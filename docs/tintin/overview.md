# Tintin++ (3Kingdoms client scripting)

Tintin++ is a MUD-style scripting client used by the 3Kingdoms game community to automate interactions and extend gameplay. This section documents how to build, install, script, and extend Tintin++ for use with the `3kdb` library and server.

- Source code: https://github.com/scandum/tintin
- 3kdb library: https://github.com/jmitchell33/3kdb

This documentation covers installation, quick-start examples, scripting API, and development notes.
