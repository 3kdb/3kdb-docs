# Installation

This page explains common ways to obtain and install Tintin++.

## From source

1. Clone the repo:

```bash
git clone https://github.com/scandum/tintin.git
cd tintin
```

2. Follow build instructions in the repository README (usually `./configure && make && sudo make install`).

## Distribution packages

Some Linux distributions provide packages — check your distribution's package manager.

## Windows

Tintin++ is primarily developed for Unix-like systems. For Windows, consider WSL or building with MSYS2. See the upstream repo for more details.
