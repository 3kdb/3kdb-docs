# API Reference

This page will explain how API/reference documentation is provided.

Options:

- Auto-generate API docs from the Tintin++ C++ source using Doxygen and then import the HTML or Markdown into `docs/api`.
- Or maintain a manual reference here with key functions, configuration files, and scripting primitives.

Next steps: choose automatic Doxygen generation or manual pages. Automatic generation requires adding a `doxygen` config and a build step that outputs Markdown/HTML under `docs/api` (or publishes a separate site and links to it).
