# Quick Start

A minimal example showing how to run Tintin++ and connect to a 3Kingdoms server.

1. Start Tintin++ (after installation):

```bash
tintin
```

2. Create a minimal script in `scripts/` with triggers and commands to automate login and simple actions. See `examples.md` for a ready-to-run script.
